OM/QM Lite - add-in Excel cho WINDOWS (thay cho Excel OM/QM)
============================================================
Hon 100 mo hinh: du bao, quy hoach tuyen tinh, ton kho, hang doi, PERT/CPM, tai chinh, chat luong...
Ket qua ra sheet moi duoi dang cong thuc Excel that. Can co MANG INTERNET khi dung (add-in duoc tai tu
https://quanphv193.github.io/POMQM/ , du lieu cua ban van nam tren may).

CAI DAT (khong can quyen quan tri)
1. GIAI NEN day du file .zip ra mot thu muc (khong chay file ngay trong cua so zip).
   Neu file tai ve bi chan: chuot phai file .zip > Properties > tick Unblock > OK, roi moi giai nen.
2. Bam dup "Cai-dat-Windows.bat" (neu SmartScreen canh bao: More info > Run anyway).
   Cua so den hien ra va bao "DA CAI XONG" - bam phim bat ky de dong.
3. THOAT HAN Excel (dong het cua so) roi mo lai Excel.
4. Excel: Insert (Chen) > My Add-ins (mui ten xuong) > muc "Developer Add-ins" > OM/QM Lite.
   Nut OM/QM Lite se hien tren tab Home.

NEU KHONG THAY "Developer Add-ins": Insert > My Add-ins > See All... > Manage My Add-ins (goc tren phai)
> Upload My Add-in > chon file manifest.xml trong thu muc nay > Upload.

GO CAI DAT: bam dup "Go-Windows.bat".

YEU CAU: Excel for Microsoft 365 hoac Excel 2019/2021/2024 ban desktop, Windows 10/11.
Huong dan chi tiet cach dung: xem file HUONG-DAN-OMQM-Lite.docx.
Luu y: ban Windows chua duoc nha phat trien thu tren may Windows that; neu loi, chup man hinh gui cho nguoi gui.
