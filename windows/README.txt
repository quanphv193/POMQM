OM/QM Lite - add-in Excel cho WINDOWS (thay cho Excel OM/QM)
============================================================
Hon 100 mo hinh: du bao, quy hoach tuyen tinh, ton kho, hang doi, PERT/CPM, tai chinh, chat luong...
Ket qua ra sheet moi duoi dang cong thuc Excel that. Can co MANG INTERNET khi dung (add-in duoc tai tu
https://quanphv193.github.io/POMQM/ , du lieu cua ban van nam tren may).

CACH 1 - CAI DAT TU DONG (khuyen dung)
1. Giai nen file .zip.
2. Bam CHUOT PHAI vao "Cai-dat-Windows.bat" > Run as administrator (Chay voi tu cach quan tri vien).
   Neu Windows bao SmartScreen: More info > Run anyway.
   (Neu file tai ve tu Zalo/Drive/Gmail bi chan: chuot phai file .zip > Properties > tick Unblock > OK, roi moi giai nen.)
3. Neu hop thoai quyen quan tri (UAC) hien ra, bam Yes (chi de tao thu muc chia se chua file khai bao add-in).
4. Thoat han Excel roi mo lai Excel.
5. Excel: Insert (Chen) > Add-ins > My Add-ins > tab SHARED FOLDER > OM/QM Lite > Add.
   Nut OM/QM Lite se hien tren tab Home.

CACH 2 - KHONG CAN QUYEN QUAN TRI (neu Cach 1 khong chay duoc)
1. Excel: Insert > Add-ins > My Add-ins > Manage My Add-ins > Upload My Add-in.
2. Chon file manifest.xml trong thu muc nay > Upload.
   (Cach nay phai lam lai moi khi cai moi; mot so ban Excel khong co muc nay.)

GO CAI DAT: bam dup "Go-Windows.bat".

YEU CAU: Excel for Microsoft 365 hoac Excel 2019/2021/2024 ban desktop, Windows 10/11.
Huong dan chi tiet cach dung: xem file HUONG-DAN-OMQM-Lite.docx.
Luu y: ban Windows nay chua duoc nha phat trien thu tren may Windows that; neu gap loi, gui thong bao loi cho nguoi gui.
